Replace the application icon with the new set in `C:\Dev\EnigmaLibs\Branding\Apps\final2\licensing`

## Context & constraints

- **The new artwork** is FEATURE-1ECA's drawing (a certificate with a green seal, LIC-A2, *Soft* palette:
  blue `#6A9BF4`, darker blue `#4A72C4`, green `#63C77D`) **without the dark rounded tile**: the background
  is transparent, and the certificate's outline is cut where the seal sits so nothing shows through it.
  Generated by `Branding/Apps/export.py final2`, which the SVGs' header comments name.
- **The new `.ico`** holds the same ten 32-bit RGBA PNG frames as today's (16, 20, 24, 32, 40, 48, 64, 96,
  128, 256). Each frame is byte for byte the matching `png/enigma-licensing-N.png` (checked while planning).
- **Where the icon lives** (unchanged since FEATURE-1ECA / FEATURE-CF21 / FEATURE-F319 / FEATURE-0156):
  - `src/Enigma.Licensing.Desktop/Assets/appicon.ico` — `<ApplicationIcon>`, `MainWindow`'s `Icon`, and the
    `app.ico` the csproj copies beside the executable (`TargetPath="app.ico"`);
  - `src/Enigma.Licensing.Desktop/Assets/app-256.png` — the About dialog's image, the `.ico`'s 256 frame
    byte for byte;
  - `packaging/linux/icons/enigma-licensing-{16,24,32,48,64,96,128,256}.png` — what `install.sh` installs
    (`ICON_SIZES`), each the `.ico` frame of its size byte for byte.
- `AppIconTests` (desktop suite) compares the output `app.ico` with the asset, so it follows the asset.
- The repository carries no SVG master today; the masters' home is the Branding repository (CLAUDE.md,
  FEATURE-1ECA: "A redesign happens in the Branding repository, never here").
- The source directory is outside the repository and is left in place.
